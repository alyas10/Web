# NetGuard AI

Веб-приложение для тестирования моделей машинного обучения в задаче обнаружения и классификации сетевых атак. Позволяет загружать сетевой трафик (CSV или PCAP/PCAPNG), прогонять его через предобученные ML-модели и просматривать результаты, метрики и аналитику датасета через веб-интерфейс.

## Краткое описание

Проект реализует полный цикл работы с сетевым трафиком для целей кибербезопасности:

- **Загрузка данных** из файлов `.csv` и `.pcap`/`.pcapng` (через `scapy`) с чанковым чтением и индикацией прогресса.
- **Предобработка** — приведение признаков к формату модели, нормализация, обработка пропусков, балансировка классов, конвертация типов.
- **Предсказание** четырьмя алгоритмами: **LightGBM**, **XGBoost**, **Random Forest**, **Isolation Forest** (One-vs-Rest с Z-score калибровкой).
- **Визуализация и метрики** — accuracy, F1, ROC-AUC, confusion matrix, отчёты по классам.
- **EDA-отчёт** по датасету (`docs/report.md`) с графиками.

Датасет — около 4.5 млн записей сетевого трафика, 63 признака (числовые, категориальные, временные); основные протоколы TCP (64%), ICMP (15%), HTTP (12%).

### Технологии
Flask 3, scikit-learn, LightGBM, XGBoost, pandas/numpy, matplotlib/seaborn/plotly, scapy, PySide6 (desktop-обёртка), PyInstaller (сборка).

## Принцип работы

Архитектура построена на разделении ответственности по слоям:

```
Файл (CSV/PCAP)
      │
      ▼
data_loader/         ─ чтение «сырого» DataFrame
  ├─ csv_loader.py       CSVDataLoader
  ├─ pcap_loader.py      PcapScapyDataLoader (+ извлечение ML-признаков)
  └─ base.py             DataPipelineAdapter ─ подготовка данных
      │                    (нормализация, согласование признаков,
      ▼                     балансировка, конвертация типов)
model_manager/       ─ загрузка артефактов и предсказание
  └─ model_manager.py    ModelManager (кэш моделей, predict по алгоритмам)
      │
      ▼
pipeline/<algo>/test/ ─ сохранённые модели и артефакты
  (.joblib, label_encoder, scaler, feature_names.txt, metrics.json)
      │
      ▼
modules_site/        ─ Flask Blueprints (веб-интерфейс)
  ├─ dashboard           главная панель
  ├─ data                загрузка/обработка файлов, прогресс
  ├─ models              список моделей, детали, /predict
  ├─ results             метрики, графики, confusion matrix
  ├─ dataset_analys      рендер EDA-отчёта из report.md
  └─ settings            конфигурация приложения (app_config.json)
```

Поток обработки:

1. Пользователь загружает файл через веб-интерфейс (`/data/upload`). Обработка идёт в фоновом потоке, прогресс опрашивается по `session_id`.
2. Соответствующий `DataLoader` читает файл в DataFrame. Для PCAP дополнительно извлекаются признаки (флаги протоколов, частоты IP, интервалы пакетов, известные порты).
3. `DataPipelineAdapter` сопоставляет колонки с признаками модели, добавляет недостающие, приводит типы и при необходимости нормализует/балансирует — согласно настройкам в `app_config.json`.
4. `ModelManager` загружает артефакты выбранного алгоритма (кэшируются), приводит входные данные к ожидаемому набору и порядку признаков и вызывает `predict`. Для Isolation Forest применяется масштабирование `scaler.joblib` и калиброванное One-vs-Rest предсказание.
5. Числовые предсказания декодируются `LabelEncoder`'ом в названия классов и отображаются на страницах результатов вместе с метриками и графиками.

Настройки (имя проекта, лимит размера файла, флаги `auto_preprocess` / `normalize_features` / `balance_classes`, уведомления, тема) хранятся в `app_config.json` и редактируются на странице `/settings`.

## Как запускать

### Требования
- Python 3.12
- Зависимости из `requirements.txt`

### Установка

```bash
python -m venv venv
# Linux/macOS
source venv/bin/activate
# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

### Запуск веб-версии (Flask)

```bash
python app.py
```

Приложение поднимется на `http://0.0.0.0:5000` (по умолчанию `debug=True`). Откройте в браузере:
- `/` или `/dashboard` — главная панель
- `/data` — загрузка трафика
- `/models` — модели и предсказание
- `/results` — метрики и графики
- `/dataset` — EDA-отчёт
- `/settings` — настройки

### Запуск desktop-версии (окно PySide6)

```bash
python run_gui.py
```

Скрипт запускает Flask в фоновом потоке (порт 5000, локально) и открывает интерфейс в нативном окне на базе QtWebEngine.

### Сборка в исполняемый файл

В зависимостях есть PyInstaller — проект можно собрать в standalone-приложение (код учитывает `sys._MEIPASS` для путей к ресурсам):

```bash
pyinstaller run_gui.py
```

## Структура проекта

| Путь | Назначение |
|------|------------|
| `app.py` | Фабрика Flask-приложения, регистрация Blueprints, инициализация общих объектов |
| `run_gui.py` | Desktop-обёртка на PySide6 (Flask + QWebEngineView) |
| `app_config.json` | Настройки приложения |
| `requirements.txt` | Зависимости Python |
| `data_loader/` | Загрузчики CSV/PCAP и адаптер подготовки данных |
| `model_manager/` | Загрузка моделей, предсказание, метрики, утилиты |
| `modules_site/` | Flask Blueprints (страницы и API) |
| `pipeline/` | Сохранённые модели и артефакты по алгоритмам |
| `graphics/` | Визуализация датасета |
| `templates/`, `static/` | HTML-шаблоны и статика (CSS/JS) |
| `docs/` | EDA-отчёт (`report.md`) и Jupyter-ноутбуки обучения моделей |
| `test/` | Тестовые данные и тесты |
